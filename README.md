# C题 · 新能源汽车节能建模成果

2026年第二届全国大学生仿真建模应用挑战赛 · 队伍 **CSF2605207**。

我们用模型算清电动车的耗电、电量和温度，用行驶数据校准，再比较怎样回收刹车能量、怎样调节温度更省电。

在同条件的“90分钟驾驶＋120分钟停车温控”模型实验中，25℃、40℃、−10℃的总节能率分别为 **11.83%、9.85%、0.70%**。这些是模型实验结果；预调温未计，实车效果仍需验证。

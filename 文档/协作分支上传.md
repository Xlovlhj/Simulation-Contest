# 上传到 Simulation-Contest 的 ybs-b 分支

本目录对应仓库 `https://github.com/Xlovlhj/Simulation-Contest.git` 的独立B题分支 `ybs-b`。2026-10-18查询时，远端只有 `ybs-c`。本次在B题目录创建独立Git历史，并仅推送 `ybs-b`。

## 第一次上传

在当前文件夹打开PowerShell，按组执行。出现报错时先停下，不继续执行后面的命令。

### 1. 确认当前位置和工具

```powershell
Get-Location
Get-ChildItem -Force
git --version
git lfs version
```

当前位置应为 `Simulation-Contest-ybs-b`，文件清单包括 `README.md`、`.gitignore`、`.gitattributes`、`应用`、`复现`等。

### 2. 初始化B题仓库和LFS

```powershell
git init -b ybs-b
git lfs install --local
git remote add origin https://github.com/Xlovlhj/Simulation-Contest.git
git branch --show-current
git remote -v
```

应看到当前分支 `ybs-b`，origin地址是上面的多人仓库。LFS规则已经写入 `.gitattributes`；ZIP和MP4从首次提交开始使用LFS。

### 3. 添加文件并检查LFS

```powershell
git add .
git status --short
git lfs ls-files
git diff --cached --stat
```

首次应有115个项目文件。`git lfs ls-files`应显示两个文件：`复现/B题支撑材料_最终修订版.zip`、`演示/B题仿真演示_最终修订版.mp4`。LFS中出现这两个文件后再提交；实际字节仍留在工作目录，Git索引保存LFS指针。

### 4. 提交到本机

```powershell
git commit -m "Add B traffic simulation project with Git LFS"
```

如果Git提示没有作者身份，先设置你本人实际使用的Git姓名和邮箱。只在此仓库设置即可，示例中的文字应替换成真实信息，再重试commit：

```powershell
git config user.name "你的Git提交姓名"
git config user.email "你的GitHub邮箱或noreply邮箱"
```

### 5. 推送到指定分支

```powershell
git push -u origin ybs-b
```

首次HTTPS推送若弹出浏览器登录，使用有该仓库写权限的GitHub账号完成授权。Git LFS会通过本仓库安装的pre-push钩子先上传二进制对象。

完成后打开 `https://github.com/Xlovlhj/Simulation-Contest/tree/ybs-b`，查看README、源码和文件。最后执行：

```powershell
git status
git ls-remote --heads origin ybs-b
```

应显示本地无待提交修改，远端存在 `refs/heads/ybs-b`。这套准备未代替你执行commit或push。

## 后续更新

先将原开发目录的实际修改同步到此上传副本，再逐条执行：

```powershell
git pull --ff-only origin ybs-b
git add .
git lfs ls-files
git diff --cached --stat
git commit -m "Update B traffic simulation project"
git push origin ybs-b
```

多人协作时，如果pull或push提示历史分叉、非快进、冲突或远端已有不同的 `ybs-b`，先停下并保留文件，按实际远端历史整合。不要使用 `--force` 或 `--mirror`。

## 常见报错

| 提示 | 做法 |
|---|---|
| `Repository not found`、403或permission denied | 确认登录账号及仓库地址，请仓库管理员授予该账号写权限 |
| LFS容量、流量或权限错误 | 由仓库管理员检查LFS额度和权限；保留本地文件后重试推送 |
| `remote origin already exists` | 先运行 `git remote -v` 检查是否进入了正确的新目录，不直接覆盖个人仓库的origin |
| `non-fast-forward`或`fetch first` | 远端分支已变化；不强推，先取得新历史再决定如何合并 |

## 下载与复现

协作者安装Git LFS后克隆指定分支：

```powershell
git clone --branch ybs-b --single-branch https://github.com/Xlovlhj/Simulation-Contest.git
Set-Location Simulation-Contest
git lfs install --local
git lfs pull
git lfs ls-files
```

确认ZIP和视频为完整文件后，按根目录README复算。使用Git克隆和 `git lfs pull` 可明确取得LFS对象；网页 `Download ZIP` 是否含完整LFS内容取决于仓库归档设置。

## 最终稿确定了什么？

- 第一问：保留25℃公开CLTC-P基准、能量账本和7参数双幅度灵敏度；容量160 Ah参考、80 Ah对照。
- 第二问：保留原Rint校准与条件区间，另推荐RC作回顾电压预测；588/600均不称新盲测，滚阻和RC欧姆内阻贴界如实解释。
- 第三问：原模型支持控制和长程结果；常温、高温有条件性节能证据，低温不作稳健节能结论。传感误差59/60及严格终温0/60同时保留。
- 未解决项：同车独立路阻、宽SOC电压、真实温度和传感器校准。论文说明其影响和适用范围，不宣称全部实车验证。

本次集中修订摘要、符号、优化约束表达、引用顺序和结论口径，不新增拟合、寻优或物理实验。

用户最新确认队伍号留白、人工核验尚未完成。因此当前是**最终技术稿和待提交材料**，尚不能标记为手续齐全、可以直接上传的全部作品。

## 同学怎样复现？

发完整`C题_同学复现包.zip`，完整解压进入`C题复现工程`后运行：

```powershell
python reproduce.py verify
python reproduce.py prepare
python -m pip install -r records/requirements-lock.txt
python reproduce.py all
```

原主实验核对17项关键数值及34项自动检查。新增外部数据和RC试验需另运行`python scripts/recompute_extension.py`；此前已完成1791个数值及状态的隔离重算。本次定稿不改变科学代码及数据，具体新包运行证据以随包核查摘要为准。

精简支撑包省略官方原始题包，用`prepare --official-data "官方题包路径"`补入；不要给同学只发这个精简包。完整说明见[交付与复现说明](交付与复现说明.md)。

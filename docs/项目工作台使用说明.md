# 项目工作台：只开这一个入口

双击工程根目录的 **C题项目管理.html**。不用启动服务，不用联网。

## 怎么看

| 想做什么 | 去哪里 |
|---|---|
| 看项目在做什么、下一步做什么 | 首页 |
| 看各阶段完成到哪里 | 首页进度条；展开“查看工作项” |
| 快速理解任务 | 执行计划·精简 |
| 查完整步骤和评分要求 | 执行计划·完整 / 赛题解读 |
| 看公式和通俗解释 | 建模原理 / 控制原理 |
| 学参数与术语 | 参数与术语 |
| 看图和演示视频 | 结果与图表 |
| 找以前做过什么、为什么这样选 | 开发日志 / 关键决定 |
| 查原始题目或提交规范 | 赛题与附件 |

左侧切换内容，右侧阅读。长文有本页目录；图片可点击放大。手机窄屏点击“目录”切换。

## 学习记录怎么用

1. 每条词条都有专业解释、人话解释、单位、来源或注意点。
2. 理解并掌握后，勾选前面的小方框。词条变浅，并计入学习进度。
3. 可按“全部 / 未掌握 / 已掌握”和词条分类筛选，也能搜索词条。
4. 勾选自动保存在当前浏览器。换电脑、换浏览器、清理浏览器数据或移动文件前，点击“导出学习记录”。
5. 在新位置点击“导入记录”，选择导出的JSON；确认后替换当前勾选。不是本项目的记录会拒绝导入。

若浏览器不允许保存，页面仍可用；关闭前导出即可。HTML更新不会主动清空勾选，但浏览器是否沿用同一本地文件的存储，仍受浏览器和文件位置影响。

## 怎样找内容

右上角搜索覆盖全部文档和术语。多个关键词可用空格分开，点击结果直接跳转。快捷键为 **Ctrl K**；搜索框中按 **Esc** 返回原页。

## 开发日志为什么也放进来

日志保留做过的事、失败、决定和下一步，是后续恢复上下文的依据。它有独立页签，首页只显示当前重点。历史阶段报告也保留，但会提示它属于历史快照。

## 进度和结果怎样理解

进度条是明确工作项的完成比例，展开后可逐项核对。它不是比赛得分、模型精度或成功概率。例如“扰动实验做完”与“每组扰动都通过”是两回事，失败仍然保留。

参数参考值和暂定校准值分别列出，数值从现有配置读取。页面中的图与视频来自真实运行产物，没有重新制造结果。

## 后续文档如何同步

这是给维护者看的最短流程：

```powershell
python run.py portal
```

- 新增或修改`docs/`中的Markdown，会自动生成独立页签；支持子目录。
- `results/`和`records/`根目录下的Markdown，以及开发日志、README，同步进入相应分组。
- 新阶段完成后，维护者同步更新`portal/project.json`的当前重点与工作项，并更新开发日志和机器状态，再运行上述命令。
- 运行现有`run.py`仿真、辨识或视频命令，结束时也会同步工作台。单纯阅读不必运行命令。
- 页面是生成时的文档快照；浏览器刷新不能读取刚改动的Markdown，须先重新生成。学习勾选保存在浏览器，与文档快照分开。

正文、公式、流程图、结果图片及开发样片已嵌入HTML。只复制HTML也能阅读这些内容；PDF、Word和Excel原件链接仍需保留工程目录。

## 可重复检查

可选安装`requirements-portal-check.txt`，再运行`python scripts/check_portal.py`。脚本用本机Chrome或Edge检查离线打开、页签、全部公式、学习记录、搜索、视频和390px窄屏；结果保存在`results/portal_checks/`。

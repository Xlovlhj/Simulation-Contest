## 同学首次打开

1. 将共享包完整解压到普通文件夹，进入`C题复现工程`。
2. 阅读根目录README，双击`C题项目管理.html`可先看论文、术语和进度。
3. 打开终端，确认位于该目录，建议使用Python 3.12。本次实际版本与库版本见`records/requirements-lock.txt`及交付核查记录。
4. 先核对文件，再恢复轨迹并安装依赖，最后运行复现。

```powershell
python reproduce.py verify
python reproduce.py prepare
python -m pip install -r records/requirements-lock.txt
python reproduce.py all
```

`verify`核对刚解压时的逐文件SHA256；修改源码或文档后校验不再通过是正常现象，先保留原包再开展修改。`prepare`恢复轨迹并核对9份官方输入。共享包已含官方输入，不需另找Excel。

`all`会在`reproduced/all_随机后缀/`建立隔离副本运行，原始交接材料保持不动。程序结束后，根目录生成`REPRODUCTION_REPORT.json`，其中记录退出状态、结果目录及关键数值核对。失败时保留目录以便排查，不自动删文件。

## “复现”具体重算什么

| 命令 | 实际动作 |
|---|---|
| python reproduce.py all | 重算数据审计、基准/灵敏度、冻结参数的分路程评价、控制对照/扰动及图表；辨识点、规则选择、长程结果、300次非线性诊断在指纹一致时复用 |
| python reproduce.py refit | 在隔离副本中重新辨识575/596的五个共享参数，输出与冻结点的差异；不把600用于调参 |
| python reproduce.py long | 在隔离副本中重新运行长程/停车/测温偏差评价，重新生成全列长轨迹；耗时更长 |
| python reproduce.py improve | 在隔离副本保留已有修正实验，再重算OCV候选、滚阻下界诊断、温度观测与回温实验；先做6项解析检查，并比较新结果 |
| python reproduce.py paper | 用冻结证据重建技术论文及AI详情，需要可选排版环境 |

`all`不是重新运行300次非线性优化的声明。完整算法、固定种子、边界、逐次状态和断点都已给出；需要从头重算非线性重拟合时，应在隔离副本移走结果与断点并保留原始版本，再调用`bev.reliability.run_reliability(recompute=True)`。这项耗时工作不属于默认交接核查。

**复现本轮修正需另运行`python reproduce.py improve`。** 它不直接复用阶段八缓存，会先做6项解析检查，再从头重算新训练、滚阻边界及热实验。结果在`reproduced/improve_…/records/remediation_summary.json`，根目录运行报告会更新为本次任务；需要保留上次all报告时，请先另存。重点核对停车18/18、精确模型30/30、失配压力20/60、步长18/18，以及两段回顾电压RMSE约8.54/13.33 V。更多解释见[问题修复与结果说明](问题修复与结果说明.md)。

本次已从新解压的同学包完整运行此命令，6项解析检查通过，202个数值与保存结果一致。摘要见`records/remediation_runtime_verification.json`。这是已有本机环境的实际重算记录；其他机器仍需安装依赖并自行运行。

## 精简支撑包有什么不同

比赛规范允许不重复提交官方原始数据，且要求支撑包≤20 MB。因此`C题_支撑材料.zip`不含四份官方Excel及原始赛题/规范，也不含承诺书；使用前将完整官方题包准备好：

```powershell
python reproduce.py verify
python reproduce.py prepare --official-data "完整官方题包的路径"
python -m pip install -r records/requirements-lock.txt
python reproduce.py all
```

程序按文件名与SHA256将9份官方输入补到约定位置；其中承诺书原模板只在接收者本机从官方题包补入，并没有放入比赛支撑压缩包。不能拿另一版本Excel覆盖后继续称复现原结果。

精简包的6条90分钟驾驶+停车长轨迹只保留时间、步长、SOC、温度、电池端功率等绘图和电能核算所需列，保留原CSV数值文本，不降采样、不改精度；另17条轨迹保留全列。共享包23条均为原始全列CSV。两包都附所有计算代码；`long`可重算全列长轨迹。

# 三问任务与成果速览

**项目一句话：用仿真算清电动车的耗电、剩余电量和温度，再用行驶数据校准模型、比较节能策略。**

| 小问 | 要做什么 | 通俗理解 |
|---|---|---|
| 一：基础建模 | 建立动力、电池、热管理机理模型，完成25℃ CLTC基准、能量分解和至少5个参数的灵敏度排序 | 造一辆“虚拟电动车”，看看电用到哪里，哪些因素最费电 |
| 二：参数校准 | 用四段行驶数据估计空阻、滚阻和内阻，比较误差，给出至少2个参数的不确定性区间 | 拿真实行驶记录校准这辆车，并检查参数到底能不能估准 |
| 三：节能优化 | 联合调整制动回收、冷却和空调/加热，比较能耗、约束、实时性和落地条件 | 在完成相同行驶任务、满足温控要求的前提下，尝试更省电的开法和温控方法 |

阅读提示：误差指标越小越好；节能率越大表示相对基准少用的电越多。下面区分仿真结果与实测数据比较，不把二者混为一谈。

## 第一问：这辆虚拟车能算出什么？

**已做：** 建立纵向动力、电机、电池和电池/座舱热模型；计算能量流、SOC和温度轨迹；完成7个参数、两种扰动幅度的灵敏度分析与排序。

**通俗解释：** 给车一张“每秒开多快”的表，模型就能逐步计算耗电、回收多少电、剩多少电，以及电池和车内有多热。

### 主要结果

条件：25℃、30分钟CLTC-P，初始SOC 80%，160 Ah参考容量，原Rint电池模型。CLTC速度序列由两个公开仓库交叉核对，未直接取得官方原始工况文件。

| 指标 | 结果 | 怎么理解 |
|---|---:|---|
| 行驶里程 | 14.480 km | 完成同一张速度表所走的距离 |
| 电池净输出电能 | 2.035 kWh | 扣除充回电池的电能后，本次用电量 |
| 百公里能耗 | **14.05 kWh/100 km** | 按本次平均水平折算的百公里用电量 |
| SOC变化 | **80.00% → 76.53%** | 剩余电量下降约3.47个百分点 |
| 电池最高温度 | 25.39℃ | 模型算出的温度，尚无本车测温数据验证 |
| 能量分解 | 驱动直流侧2.234 kWh；回收直流侧0.386 kWh | 能量在不同位置统计；回收到直流侧的电能不等于最终存入电池的电能 |
| 直流侧能量账本残差 | 约3.6×10⁻¹⁶ kWh | 模型内部收支一致；不等于实车预测无误差 |

**本问结论：** 基准仿真、曲线、能量账本和灵敏度排序已经完成。附件容量冲突按160 Ah参考、80 Ah对照透明处理，不能认定哪一项是官方笔误。

## 第二问：模型与行驶记录接近了多少？

**已做：** 审计4段路程、6944条记录；仅用575/596训练，估计指定参数并讨论耦合；完成校准前后比较、非线性重拟合区间，以及原Rint、OCV缩放、一阶RC三种电压模型的对照。

**通俗解释：** 先用两段记录“调车”，再看其他路程算得怎么样。还要防止不同参数互相补偿，造成“结果对上了，参数却未必是真的”。

### 校准前后：原Rint模型

| 数据 | 能耗误差：校准前 → 后 | SOC轨迹RMSE：校准前 → 后 |
|---|---:|---:|
| 训练路程575/596 | 平均绝对百分比误差 **16.39% → 3.53%** | **3.30 → 2.08** 个百分点 |
| 路程588 | 单段绝对百分比误差 **16.48% → 0.83%** | **3.99 → 2.66** 个百分点 |
| 路程600 | 单段绝对百分比误差 **13.90% → 4.41%** | **3.71 → 2.56** 个百分点 |

### 参数估计及不确定性

| 参数 | 原Rint校准值 | 95%条件百分位范围 |
|---|---:|---:|
| 空气阻力系数 Cd | 0.3644 | [0.1661, 0.4331] |
| 滚动阻力系数 Cr | 0.00302 | [0.00300, 0.01167] |
| 电池参考内阻 Rref | 0.07128 Ω | [0.06197, 0.08565] Ω |

范围来自训练数据内200次非线性块重拟合，依赖原模型、误差假设和参数边界，不保证实车总体95%覆盖。**52%的滚阻估计贴下界，滚阻可靠性仍未解决。** 这些区间属于原Rint模型，不能套在新RC模型上。

### 电压改进：保留原方案，再选新方案

| 路程 | 原Rint电压RMSE | OCV缩放电压RMSE | 新一阶RC电压RMSE |
|---|---:|---:|---:|
| 588 | 15.04 V | 8.54 V | **6.03 V** |
| 600 | 25.66 V | 13.33 V | **8.30 V** |

新RC的两段能耗误差分别为0.78%、4.36%；SOC误差分别为2.64、2.59个百分点。**推荐一阶RC用于电压预测。** 它增加了电池电压随负载变化的动态过程，可以理解为“除了立即压降，还记住了刚才的用电影响”。

**本问结论：** 能耗和SOC校准有效，电压已有进一步改善；两段588/600均已被查看，因此本轮属于回顾比较，不能称全新盲测。宽SOC电压精度和参数真实物理值仍缺证据。EPA外部路阻数据已试用，固定外部等效值后训练目标恶化35.88%，未采纳替换。

## 第三问：怎样省电，省了多少？

**已做：** 在72组规则候选中比较回收、冷却和座舱温控策略；每5秒依据当前状态决策；完成公平对照、模块消融、连续驾驶、停车热恢复和测温误差压力试验。

**通俗解释：** 该回收时多回收，该开空调时开空调；还要把停车后恢复温度所用的电算进去，避免仅靠“少制冷、留下热量”制造节能。

### 主要结果：原Rint控制模型

条件：初始SOC 94%，座舱预调到24℃；双方条件一致，预调温耗电未计入。下表为**驾驶90分钟＋停车温控2小时的总账**，不是第一问的30分钟基准。

| 环境温度 | 节能率 | 节省电能 | 解释 |
|---|---:|---:|---|
| 25℃ | **11.83%** | 0.721 kWh | 在该名义仿真条件下有效 |
| 40℃ | **9.85%** | 0.855 kWh | 在该名义仿真条件下有效 |
| −10℃ | **0.70%** | 0.097 kWh | 收益较小，误差压力试验不支持稳定低温节能 |

上述三组满足所设热终态接近条件。原扩展试验18组中17组达标；共同增加到达前冷却后，修正策略18/18组达标。旧失败保留。

### 测温不准时，还可靠吗？

采用直接测温反馈和1.1℃目标裕量，在假设的±1℃偏差、±0.05℃噪声及热参数失配下：

| 检查 | 结果 | 说明 |
|---|---:|---|
| 取消严格座舱终温条件后，其余约束通过 | **59/60** 个单策略试验 | 仍有1个低温优化案例不舒适 |
| 基准与优化双方均通过 | **29/30** 对 | 配对通过才可公平比较 |
| 原严格24±0.1℃终温条件通过 | **0/60** | 精确终温保证未解决；0.1℃是自设条件 |
| 双方可行且理想保守热核算后仍节能 | **20/30** 对 | 低温10对均无正收益 |

**本问结论：** 常温、高温有条件性节能证据；低温收益不稳，真实传感器偏差未校准。72组候选中的较优规则不等于连续控制空间的全局最优，5秒决策也不等于已在实车硬件上验证实时性。**本问控制及长程结果沿用原模型，不能归为新RC模型的节能成果。**

## 指标怎么读？

| 词条 | 通俗解释 |
|---|---|
| SOC | 电池剩余电量百分比 |
| SOC RMSE / 个百分点 | 整条电量曲线的综合误差；例如80%与78%相差2个百分点 |
| 电压RMSE / V | 整条电压曲线的综合误差，越小越好 |
| APE / % | 一段路程总耗电量的绝对百分比误差 |
| MAPE / % | 多段路程APE的平均值 |
| 节能率 / % | 相对同条件基准少用的电量占比，不同时间范围不可直接混用 |

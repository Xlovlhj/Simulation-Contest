# 参数可靠性：为什么拟合得好，也可能没估准

**本轮结论：计算完成，滚阻仍不够可信。** 300次非线性重拟合均正常结束，但主分析中52%的滚阻估计贴着工程下界。原参数没有更换；完整数字见[阶段五报告](../results/阶段五进展.md)。

## 先分清三个问题

| 你想知道什么 | 怎么检查 | 本项目的情况 |
|---|---|---|
| 程序有没有按方程算 | 解析例子、物理守恒、步长减半 | 34项程序检查通过；不代表真实车辆已经验证 |
| 模型能不能预测记录 | 留出整段路程，比较预测与实测 | 能耗有所改善，跨SOC的电压预测仍有失败 |
| 估出的参数是不是真实值 | 区间、参数补偿、边界和独立实验 | 滚阻仍靠下界，缺少独立道路阻力等验证 |

**通俗理解：** 算对一道“账目题”，不等于账本里的每个单价都填对。风阻算少一点、滚阻算多一点，也可能凑出相近总电耗。

## 风阻和滚阻为什么会互相补偿

滚阻可以理解为轮胎滚动时持续受到的阻碍；风阻是车辆推开空气需要付出的代价。简化平路模型为：

$$P_{\mathrm{road}}=mgC_rv+\frac12\rho A C_dv^3.$$

这里$v$是车速，$C_r$控制滚阻，$C_d$控制风阻。

**人话：** 车速翻倍，滚阻功率约翻倍，风阻功率约变成八倍。多种车速有助于分清两者；如果只看一个速度下的总功率，就容易分不清各自贡献。

本项目训练路程575和596的平滑最高车速分别约75和118km/h，596约28%的时间在80km/h以上。因此不能把问题简单解释为“完全没有高速”。实际模型的局部响应方向可以区分，但仍相似；附件耗电、电池误差、速度缺口等也会影响估计。满秩只表示局部没有完全重合，不表示精度足够。

## 这次300遍到底在做什么

我们没有凭空增加300辆实测车，而是反复检查：**如果现有误差有一点不同，重新拟合出来的参数会变多少？**

1. 只用原训练575/596，固定原模型、输入和参数上下界。
2. 取冻结模型的误差；把同一段时间里的各通道误差一起保留或翻转正负。
3. 围绕原冻结预测构造扰动目标，重新求解五个参数。这样既保留一段时间内共同波动，也正确保持扰动中心。
4. 主分析按40秒一块，算200次；另用20秒、80秒各算50次作对照。随机种子固定，所有尝试保留。

这叫“非线性分块wild重抽样”。“非线性”指每遍都重新跑原模型再拟合；“分块”指不会把时间相关误差当成互不相关的独立小点。

各通道共用块符号，总能量也按功率窗贡献一致汇总。但伪响应未必对应真实可实现的一趟车程；这是固定输入下的统计诊断。

## 52%贴下界，意味着什么

原工程搜索规定滚阻不能小于0.003。主200次重拟合中，104次贴着这个下界；主分位范围约为[0.00300，0.01167]。

**人话：** 给小球装了一面墙，小球不会滚到墙外。很多小球挤在墙边，不能说明墙的位置就是真实答案。

原线性近似给出的滚阻区间约为[−0.00555，0.01224]，穿过零。这个结果仍保留，用来提醒我们局部估计不稳定。新的有界计算不能出现负滚阻，部分原因是预先禁止了它；不能把“不再出现负数”当成问题已经解决。

原冻结滚阻仍为0.0030244；没有用新分布中位数替换它，也没有修改原控制规则。

## 新范围该怎样读

| 参数 | 原冻结估计 | 主分析2.5%—97.5%分位范围 |
|---|---:|---|
| 空阻Cd | 0.36443 | [0.16605，0.43311] |
| 滚阻Cr | 0.0030244 | [0.00300，0.01167] |
| 参考内阻Rref / Ω | 0.071284 | [0.061969，0.085648] |

这些是**给定模型、输入、误差重抽样办法和工程边界下的条件范围**，不能理解成“真实参数有95%的概率就在里面”，也没有证明对不同车辆具有95%的覆盖。

200次的每端2.5%尾部仅约5个样本，端点还会受随机抽样波动影响；50次的对照更粗。两半样本的尾分位差和16次不同初值审计均保留在报告中。两初值最大相对代价差约0.62%，说明仍有数值局部性，不能宣称证明了全局最优。

我们只用了两条高SOC训练路程；没有重抽样车速误差、真实温度、不同车辆或模型结构错误。多算几遍不能补出缺失的实测信息。

## 论文和答辩怎么说

可以说：“通过训练内非线性分块重拟合检查参数稳定性，发现滚阻存在明显边界堆积；在给定假设下报告条件近似区间及非线性对照，保留参数补偿和迁移不足。”

不能说：“300次计算证明三个参数都准确”“滚阻已经显著大于零”“热模型已通过实车验证”。

争取高分应靠证据完整、比较公平、结果可重现。对失败的解释要具体：现有数据能支持什么、哪里还不够、以后需要什么独立信息。对滚阻可建议独立道路阻力/滑行试验；对电池需更宽SOC及实测温度数据，不能用建议冒充已经完成。

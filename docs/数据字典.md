# C题工程数据字典

原始文件位于`../data/raw/`，保持不改动。处理脚本`../src/bev/data.py`，复制件与外层原件的哈希记录于`../records/source_manifest.json`。

| 标准列 | 原始含义/转换 | 单位 |
|---|---|---|
| vehicle_id、trip_id | 车辆与路程编号 | 无 |
| time_ms、time_s | 保留原始毫秒，除1000得秒 | ms、s |
| speed_kmh、speed_m_s | 保留原始km/h，除3.6得m/s | km/h、m/s |
| ambient_c | 环境温度，非电池温度 | ℃ |
| ac_w、heater_w | 实测空调、加热器电功率 | W |
| raw_current_a | 保留原始电流列 | A，原始符号 |
| discharge_current_a | 原始电流乘−1，约定放电为正 | A |
| soc_pct、soc | 原始百分数及除100后的比例 | %、0—1 |
| voltage_v | 实测高压电池端电压 | V |
| battery_power_w | 放电正电流×端电压 | W，净放电为正 |

`data/processed/trip_*.csv`按路程输出，保留原记录顺序和时间；不擅自插入缺失的真实观测，不从终点SOC反推测试集参数。`reference_cycle_E.csv`为附件3，仅速度输入与25℃环境列，不代表已核实CLTC。

`results/timeseries/reference_E_25C.csv`每行代表一个积分子步，含`time_start_s`、结束`time_s`和`dt_s`；功率与车速为该子步的计算值，SOC/温度同时给开始与结束状态。能量是功率×dt求和，不能误当所有行都是原始采样点后再次做梯形积分。

七参数灵敏度表中：端能耗以UI为边界，`normalized_ocv_electric_sensitivity`以UocI为边界，`normalized_soc_draw_sensitivity`以SOC下降量为指标，温度列用温差而非摄氏百分比。它们回答不同问题。

## 1. 电压：有候选路线，先判断数据能支持什么

现模型主要描述“电池电压随电量变化”与“电流造成的瞬时压降”。真实电池还存在短时记忆：刚经历大电流，电压不会立刻恢复。因此，**一阶RC等效电路**是有物理依据的候选。

| 候选办法 | 通俗解释 | 能解决的范围与限制 |
|---|---|---|
| 一阶RC极化模型 | 给电池加入一个会慢慢恢复的状态 | 可能改善动态压降；不自动补齐低SOC的OCV证据，增加的参数也可能相互补偿 |
| 电池、道路阻力分步辨识 | 先用实测电流和电压研究电池，再研究整车阻力 | 有助于减少不同模块互相“背锅”；实测电流只能作为电池子模型的辨识输入，整车正向预测仍需自行计算电流 |
| 同型号电芯的OCV与脉冲试验 | 用覆盖更多电量范围的实验补齐曲线 | 最直接，但当前没有本题电池型号及对应试验 |

本轮只检查了训练路程575/596的数据条件：SOC均主要在87.68%以上。按“电流绝对值小于2 A，超过5秒缺口即断开”统计，最长低电流片段分别约10.1秒和0.9秒，均无连续60秒片段。这个统计不证明RC模型不可辨识，但不能把这些片段当作充分静置的OCV实测。

因此，**不是没有其他方法，而是没有证据保证再加参数就能可靠修复**。目前保留候选，暂停继续追着588/600调参；它们已被查看，新分析仍须标为回顾评价。若后续试验RC，先固定协议、仅用训练数据选型，并分别检查动态电压、能耗与参数稳定性。

## 2. 测温偏差：为什么换更复杂算法也未必有效

有三条可选路线：用经校准的参考温度计标定；增加有独立误差依据的观测；依据误差上界设计鲁棒控制。前两条补充信息，后一条帮助在不确定时保护舒适和安全范围。

困难在于读数偏差和未知热量可能产生同样的观测。设读数为$y=T_c+b$，额外未知热源为$d$：

$$C_c\dot T_c=H_c(T_a-T_c)+q_0+d.$$

固定偏差时可改写为：

$$C_c\dot y=H_c(T_a-y)+q_0+(d+H_cb).$$

只观察$y$，往往只能估计合量$d+H_cb$。通俗解释：温度计高报，和车里多了一个热源，都可能让程序看到同样的现象。现模型$H_c=60$ W/K，未知50 W热量就相当于约0.83℃的偏差。没有独立信息时，不能指望换一个滤波器就消除这种混淆。

**24±0.1℃是我们自行设置的严格终温条件，赛题没有规定这个精度。** 可根据传感器校准不确定度、空间温差和响应滞后，重新设计有依据的终态条件，再用相同条件重跑双方、核算剩余热量。旧门槛下的20/60压力结果仍保留，不按新门槛追认。

当前建议：暂停真实0.1℃精度承诺。外部温度数据可以验证模型方法；无法标定我们手中并不存在的实物传感器。增加两支同样可能有共同偏差的温度计，也不等于已经得到真值。

## 3. 道路阻力：已找到官方公开数据

首选已实际取得的[美国EPA车型测试数据](https://www.epa.gov/compliance-and-fuel-economy-data/data-cars-used-testing-fuel-economy)。本轮下载并读取2026版Excel，确认包含：

- 车型、测试车辆编号、等效测试重量。
- Target Coef A、B、C：道路负荷目标系数。
- Set Coef A、B、C：台架设置系数；两者不能混用。

原表有3901条测试记录，其中458条燃料标注Electricity。它们不是458辆独立纯电车；仍须核对重复测试、动力类型、车型和配置。

道路负荷常写成$F(v)=A+Bv+Cv^2$。EPA原列单位为lbf和mph，需要先转为SI单位；**A不必等于纯轮胎滚阻，C也不必等于纯空气阻力**。轮胎、传动与速度相关损失可能混在系数里，不能直接把A除以车重就宣称得到了题目车辆的真实Cr。

优先级是：**同车同配置的独立滑行/路阻数据 → 可追溯的相近车型资料或科研实测 → 一般经验范围**。官方来源便于追溯，公开科研数据也可以使用，关键是对象、试验条件、字段、单位、许可是否匹配。

用户确认题目和附件就是全部资料。已复核C题全部3页及四份Excel的所有工作表：只给出匿名车辆455，未给出可直接匹配的真实品牌、车型或电芯型号。附件4标注“NCA/石墨典型值”，属于参考关系，不能据此认定某个实际型号。外车路阻可以用于合理性参照、先验范围或方法演示；不能直接替换本车Cr并把可靠性标为已解决。[Argonne D3](https://www.anl.gov/amd/d3)是备选入口，但本轮返回403，尚未核验其具体文件。

## 4. 容量：不等勘误也能继续完成论文

375 V×160 Ah约为60 kWh；若将30 kWh按375 V作能量等效换算，得到约80 Ah。两倍差异需要说明，不能擅自认定30 kWh是可用能量、60 kWh是标称能量。

已有基准对照可以继续采用：

| 25℃ CLTC基准，初始SOC 80% | 160 Ah参考 | 80 Ah能量等效对照 |
|---|---|---|
| 百公里端电耗 | 14.0542 kWh | 14.0542 kWh |
| 终SOC | 76.5305% | 73.0362% |

这说明**该次基准**的电耗结论不随这项口径变化，SOC明显变化；不代表所有工况、续航或控制结论都不受影响。80 Ah对照保留其他参数，是电学口径敏感性分析，不代表另一款真实电池的完整结构。

建议论文直接说明：无勘误，参考仿真采用附件160 Ah，30 kWh仅列为冲突值，另用80 Ah作对照；训练辨识的有效容量单独报告。拟合容量接近80 Ah，也不能反证官方一定写错。容量影响较大的结论只在对应口径下解释。

# 论文先看什么，接下来怎样定稿

现有[论文审阅初稿](C题论文审阅初稿.md)、[PDF审阅版](../../results/paper/C题论文审阅初稿.pdf)和[证据总表](三问证据总表.md)。初稿已覆盖三问，尚未完成队员独立工作核实、人工修改和最终提交准备。

## 建议阅读顺序

1. 看摘要，确认能用自己的话说明三问分别做了什么。
2. 看第4节，弄清电从哪来、往哪去，为什么损失不能重复计入。
3. 看第5节，分清“误差变小”和“参数估准”，理解Cr贴下界及600回顾的限制。
4. 看第6节，分清三种比较：单循环原始电耗、理想热修正、实际停车总账。
5. 对照证据表核数，修改不准确或自己不能独立解释的内容，再看PDF布局。

## 最需要队员判断的事项

| 事项 | 当前事实 | 完成标准 |

| 核心工作归属与理解 | AI辅助了建模、代码、计算与初稿；队员实际独立完成情况未提供 | 按真实情况记录队员独立工作、修改与验证；不能把“读过”当作“独立完成” |
| 参数与数据冲突 | 容量口径未获勘误，Cr仍靠边界，电压迁移失败 | 明确保留限制，不把工程搜索边界改称物理真值 |

## 本届格式，以原规范为准

论文第一页放题目、摘要和关键词，下一页起目录及正文；摘要通常不超过一页。页脚居中从1连续编号，无页眉。题目三号黑体、一级标题四号黑体居中、其他汉字小四宋体、单倍行距。PDF≤20 MB。原规范没有要求“正好30页”，不套用其他竞赛的页数和无目录规则。

当前PDF为18页浏览器离线排版审阅版；除字体族、摘要、目录和连续页码外，还从PDF实际文字核对12/16/14pt字号，防止长公式导致整篇缩小。自动检查只核查实际文件和布局，不能代替完整科学性或最终格式评审。

## 修改与同步

正文源文件为`paper/draft.template.md`，数值和表格从冻结结果生成；主文输出在`docs/论文/`。改写正文后运行`python run.py paper`，重建证据表、HTML和PDF，再同步项目工作台。直接改生成稿前请先留副本，避免下次生成覆盖。

本轮没有重跑辨识、改变参数或选择控制规则。若科研数据源确需变化，须保留旧证据版本并明确新实验，不能只手改论文数字。

下一步优先完成队员修改、针对问题的技术核对、正式视频和精简支撑材料。保持工作台作为日常阅读入口；PDF用于检查打印效果。

## 论文怎样使用这些证据

1. 先写统一边界、初值和约束，再报收益。单循环理想热修正与驾驶+停车实际总账分表。
2. SOC误差写明百分点、宏平均/池化差异；单路程APE与多路程MAPE区分。
3. 好结果与失败并列：能耗变好，同时写电压变差；有界范围同时写Cr贴下界。
4. 提案与已完成工作分开：MPC、实测温度、真实传感器校准和新盲测均未完成。
5. 科研结果来自既有冻结文件；改正文不会自动更新实验。任何数值源变化必须另立证据版本。
